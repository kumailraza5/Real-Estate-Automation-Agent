Build a production-ready SaaS application called "Real Estate Operations Agent".

The goal of this platform is NOT to create a chatbot. This is an internal business automation platform for real estate companies that automates repetitive operational tasks and improves productivity.

The platform should follow modern enterprise SaaS architecture with a clean, scalable, and modular codebase.

=========================
MAIN FEATURE
=========================

The main feature is an Automation Agent.

This is NOT a chatbot.

This is an internal workflow automation engine.

Users should be able to create workflows.

Workflow Builder should support:

Trigger

↓

Conditions

↓

Actions

Example:

WHEN

New Lead Created

IF

Budget > $500,000

THEN

Assign Senior Agent

Create Follow-up

Notify Manager

Update CRM

Another example:

WHEN

No Response For 48 Hours

THEN

Create Reminder

Notify Assigned Agent

Move Lead To Follow-up

Another example:

WHEN

Viewing Completed

THEN

Update CRM

Create Next Follow-up

Notify Sales Manager

=========================
AUTOMATION ENGINE
=========================

The backend should include an Automation Engine.

Whenever an event occurs:

Lead Created

Lead Updated

Viewing Scheduled

Deal Closed

The engine should automatically:

Read workflow rules

Evaluate conditions

Execute actions

Log execution

Update CRM

Create Tasks

Generate Notifications

Everything should be event-driven.
